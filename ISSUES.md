# PetSathi — Level 1 Issues
## Frontend Pages & Static UI (No Database Required)

**Project:** PetSathi  
**Program:** NSoC Winter Edition  
**Level:** 1  
**Focus:** Build the main website pages and user interface using HTML, CSS, and JavaScript only.  
**Backend / Database:** Not included in this level.  
**Level 2 Start Date:** **3 November 2026**

---

## 🎯 Level 1 Objective

The goal of Level 1 is to create the main PetSathi website pages and make them navigable, responsive, and visually consistent.

During this level, contributors will work only on frontend pages that do not require a database or backend connection. Use static/sample content wherever a page needs example data.

**Do not implement PHP, MySQL queries, authentication logic, database connectivity, or data persistence in Level 1.** These will be handled in Level 2 and later.

---

## 📌 Level 1 Tasks

### 1. Shared Website Layout

- [ ] Create a consistent navigation bar.
- [ ] Add the PetSathi logo/name and navigation links.
- [ ] Create a reusable footer.
- [ ] Add responsive navigation for mobile screens.
- [ ] Maintain consistent colors, typography, buttons, spacing, and page layout.
- [ ] Ensure internal navigation links open the correct pages.

**Expected pages/components:** Shared header, navigation, and footer.

### 2. Homepage

- [ ] Create the main homepage (`index.html`).
- [ ] Add a hero section introducing PetSathi.
- [ ] Add a short explanation of what PetSathi does.
- [ ] Add pet category cards.
- [ ] Add a section explaining how PetSathi works.
- [ ] Add an overview of available/planned services.
- [ ] Add featured walker cards using static sample content.
- [ ] Add a call-to-action section.
- [ ] Add a footer with relevant navigation links.

**Note:** Homepage content and cards must use static/sample data in Level 1.

### 3. About Page

- [ ] Create an About PetSathi page.
- [ ] Explain the purpose and vision of the platform.
- [ ] Describe how PetSathi helps pet owners and walkers.
- [ ] Add project goals and a short mission section.

### 4. Pet Category Pages

Create separate pages for each supported pet category. Each page should have its own relevant content and design while following the common website layout.

#### Dogs

- [ ] Create the Dogs landing page.
- [ ] Add an introduction to dog care.
- [ ] Add dog breed cards using static content.
- [ ] Add sections for nutrition, exercise, grooming, and walking.
- [ ] Add navigation to relevant dog information sections/pages.

#### Cats

- [ ] Create the Cats landing page.
- [ ] Add an introduction to cat care.
- [ ] Add cat breed cards using static content.
- [ ] Add sections for nutrition, indoor activities, grooming, and general care.

#### Birds

- [ ] Create the Birds landing page.
- [ ] Add an introduction to bird care.
- [ ] Add bird type/species cards using static content.
- [ ] Add sections for nutrition, habitat, and daily care.

#### Rabbits

- [ ] Create the Rabbits landing page.
- [ ] Add an introduction to rabbit care.
- [ ] Add rabbit breed cards using static content.
- [ ] Add sections for nutrition, exercise, grooming, and general care.

#### Other Pets

- [ ] Add an Other Pets page or category section.
- [ ] Show how additional pet categories may be introduced in the future.

**Content note:** Use responsible, general informational content. Do not present the website as a source of veterinary diagnosis or emergency medical advice.

### 5. Services Page

- [ ] Create a Services overview page.
- [ ] Add cards/sections for planned services such as dog walking and pet care.
- [ ] Explain each service briefly.
- [ ] Add clear buttons or links to relevant pages.
- [ ] Mark services that are not yet functional as coming soon.

### 6. Walker Pages — Static UI Only

- [ ] Create a Find a Walker/listing page.
- [ ] Display sample walker cards.
- [ ] Show sample information such as name, experience, service area, supported pet types, and indicative price.
- [ ] Create a static walker profile/details page design.
- [ ] Add visual filters/search controls as UI only, if required.

**Important:** Do not connect walker listings to MySQL or implement real search/filtering in Level 1. Clearly identify sample walker information as demo content.

### 7. Authentication Pages — UI Only

- [ ] Create a login page design.
- [ ] Create a registration page design.
- [ ] Add form labels, input fields, buttons, and basic client-side form validation.
- [ ] Add links between login and registration pages.
- [ ] Make forms responsive and accessible.

**Important:** Login and registration must remain frontend demonstrations. Do not implement real account creation, password storage, PHP authentication, or sessions in Level 1.

### 8. Responsive Design & Accessibility

- [ ] Make all Level 1 pages responsive on desktop, tablet, and mobile.
- [ ] Use semantic HTML elements.
- [ ] Add meaningful alternative text to informative images.
- [ ] Ensure readable text contrast and visible keyboard focus.
- [ ] Use consistent button and link styles.
- [ ] Check that images load correctly and do not overflow their containers.

### 9. Frontend Testing & Documentation

- [ ] Check all navigation links.
- [ ] Test each page at common screen sizes.
- [ ] Check for broken images and missing assets.
- [ ] Check browser console for frontend errors.
- [ ] Keep HTML, CSS, and JavaScript files organized.
- [ ] Update screenshots or documentation where useful.

---

## 🚫 Out of Scope for Level 1

The following work will be taken up in Level 2 or later:

- PHP backend implementation.
- MySQL database connection or SQL-driven pages.
- Real user registration, login, logout, and sessions.
- Saving or retrieving pet profiles.
- Real walker account creation or profile management.
- Live walker search, availability, or filtering from a database.
- Creating, accepting, rejecting, or cancelling real bookings.
- Persistent ratings, reviews, or notifications.
- Admin operations that update or retrieve database records.
- Deployment of backend functionality.

Static page designs and sample content for these features are allowed where listed above.

---

## ✅ Level 1 Completion Checklist

Level 1 can be considered complete when:

- [ ] Main public-facing pages are created.
- [ ] Pet category pages are available and navigable.
- [ ] Homepage links connect to the relevant pages.
- [ ] Walker, service, login, and registration screens have frontend-only designs.
- [ ] All pages follow a consistent visual style.
- [ ] Pages work on desktop and mobile screen sizes.
- [ ] No database or backend connection is required to view the Level 1 website.
- [ ] No broken links, missing assets, or major frontend errors remain.
